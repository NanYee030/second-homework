# 簡易消費紀錄統計系統 (Expense Tracker System)

這是一個使用 Python 撰寫的命令列（CLI）簡易消費紀錄統計系統。使用者可以透過主選單新增消費紀錄、檢視詳細消費清單以及查看統計分析結果。

---

##  功能特點

1. **新增消費**：支援消費項目與金額輸入，具備完整的輸入格式驗證（包含非數字、小數點及負數檢查），確保資料品質。
2. **顯示消費明細**：以清晰的表格格式對齊顯示所有消費紀錄與編號，金額自動格式化至小數點後兩位。
3. **顯示統計**：自動計算總筆數、總金額與平均每筆金額，並根據總金額提供對應的消費提醒提示。
4. **選單防錯機制**：使用 `while` 迴圈維持系統運作，對無效輸入給予提示並引導重新選擇。

---

##  開發環境與技術

- **語言**：Python 3
- **架構與邏輯**：使用基礎控制結構（`while` / `if-elif-else`）、資料結構（`list` / `dict`）與字串處理方法（`.strip()`, `.replace()`, `.isdigit()`, `.isascii()`）實作，未依賴任何第三方套件或 OOP 特性。
